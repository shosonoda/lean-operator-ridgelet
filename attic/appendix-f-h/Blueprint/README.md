# Retired Blueprint exposition

These fragments preserve the former operator-parameter and general-weight material,
including its supporting nodes and approximation corollary. They are outside the active
Blueprint and are not standalone build targets. The earlier mathematical code is preserved at
the fixed revision
[`525a54c`](https://github.com/shosonoda/lean-operator-ridgelet/tree/525a54cf4c341fdc5c303b7db93a6e21d101a27e),
retained as `snapshot20260929before-pruning-appendix`. That curated snapshot omits
the Blueprint; the original Blueprint sources are available at full revision
[`2434330`](https://github.com/shosonoda/lean-operator-ridgelet/tree/2434330af220e4fa019498b59f674b566777da07/OperatorRidgeletBlueprint).

Some archived infrastructure passages combine retained and retired content; the active
chapter keeps the trace and determinant results and the scalar approximation definitions.
The active legacy-link registry distinguishes removed results from moved results by
their previous identities, including when a manuscript number is reused.
